# Habits: app downloads

Downloads for the Habits habit tracker apps. The app's source code is private; this repository only holds the built apps.

**Latest version:** see [Releases](../../releases/latest).

- **Mac:** download `Habits-<version>.dmg`, open it, and drag Habits into Applications. The first time, macOS may block it: go to **System Settings → Privacy & Security → Open Anyway**. After that, the app updates itself.
- **Android:** download `Habits-<version>.apk` on your phone and open it. Allow installs from your browser if asked. The app tells you when an update is available.

Website: https://habit-tracker-rtpr.vercel.app
